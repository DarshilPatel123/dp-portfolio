# Friend-testing checklist

Use this before choosing the permanent homepage direction. Ask 3 to 5 people to test the site independently, ideally on both a phone and a desktop browser.

## Give each person these starting routes

- `index.html` — Classic Portfolio

Do not explain the intended answer before they try them. Observe which route they choose first and whether they find their way back to the normal portfolio.

## Questions to ask

1. Which version did you choose first, and why?
2. Which version felt most professional for a software developer?
3. Which version was most memorable?
4. Was any wording, button, control, or navigation unclear?
5. Would you prefer to see the normal portfolio or an interactive experience first if you were a recruiter?
6. Did every page work on your phone or browser?

## Decision rule

Use the normal portfolio as the default homepage if clarity and professional trust win. Revisit an interactive experience only after the normal portfolio is complete and people can quickly understand the professional information.
