## Week 4 — publishing readiness

- Create or connect the GitHub repository only after user approval.
- [x] Document the GitHub Pages publishing and verification sequence.
- Publish the approved static site through GitHub Pages.
- Verify the direct policy URL in a signed-out/private browser.
- Complete a final security, accessibility, mobile, and privacy review before using the URL in Google Play.

## Release rules

- `main` is not changed until the user explicitly approves a squash merge.
- The privacy route remains unlinked from the portfolio and contains no link back.
- No privacy policy is submitted to Google Play while its developer identity or contact email is a placeholder.
- GitHub hosting is not configured or uploaded without separate user approval.
