# Software Portfolio

A static, dependency-free portfolio foundation designed for GitHub Pages.

## Current routes

- `/` — normal, recruiter-friendly portfolio
- `/prototypes/workspace/` — original interactive Workspace concept

The Dot-and-Box privacy-policy route will be added only after a focused audit of the game's actual data handling, permissions, and third-party SDKs. It must not be published with guessed disclosures.

## Local preview

Open `index.html` in a browser for the normal portfolio, or `prototypes/workspace/index.html` for the interactive concept. Both use only relative paths and require no build step.

## Week 1 scope

- Establish the accessible normal portfolio structure.
- Provide an isolated, original interactive concept for review.
- Replace temporary profile content after reviewing the résumé and receiving approved project details.
- Prepare a verified privacy-policy page after the game data audit.
