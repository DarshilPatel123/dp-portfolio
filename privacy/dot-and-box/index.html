Privacy Policy

Effective date: 27 September 2026

This policy describes the current offline version of Dots & Boxes. It will be reviewed before any future release changes the game's data practices.

This Privacy Policy describes how Silent Gaming handles information in the Dots & Boxes mobile game.

Information collection

Dots & Boxes is an offline game. The current version does not create user accounts and does not collect, store, transmit, sell, or share personal information or device data.

Advertising, analytics, and online services

The current version does not include:

  • Advertising or advertising identifiers.
  • Analytics, crash-reporting, or tracking SDKs.
  • Social login, cloud storage, or online multiplayer.
  • Cookies or tracking technologies within the game.

Local game information

Match state and theme choices are kept only in memory while the game is running. They are discarded when the app closes. No personal information is retained, so there is no personal data to review or delete.

Permissions

The game does not request access to contacts, location, camera, microphone, photos, or other sensitive information. This statement will be reviewed before any release that adds permissions.

Children's privacy

The game is suitable for general audiences and does not knowingly collect personal information from children.

Data security and retention

Because the current version does not collect or transmit personal information, it does not retain personal information on developer-controlled systems.

Changes to this policy

This policy will be updated before any release that adds data collection, accounts, ads, analytics, online services, new permissions, or different data-handling practices. The effective date will be updated at the same time.
